Odoo URL Replacement

Odoo 18 CE & EE White Labeling General Settings Integration Safe Defaults

Replace the default /odoo segment in backend URLs with your custom brand name. For instance, https://yourdomain.com/odoo/action-250 becomes https://yourdomain.com/brand/action-250. Fully configured via General Settings with immediate effect, no server restart or reverse proxy rewrite required!

Seamless General Settings Integration

Enable or disable URL replacement and set your custom brand slug directly from Settings → General Settings.

Changes apply immediately on Save — no server restart or web server rewrites needed.

Easy Toggle

Enable or disable URL replacement with one click directly from General Settings. Reverts to 100% native behavior when disabled.

Smart Redirection

Automatic 302 redirects from legacy /odoo and /web URLs to your branded URL while preserving query parameters and hashes.

Safe & Protected

Strict brand validation prevents route collisions with system keywords. Clean uninstallation restores default Odoo settings automatically.

How It Works
1
Install Module

Install cleanly with only standard web and base_setup dependencies.

2
Open Settings

Navigate to Settings → General Settings to find the URL Replacement section.

3
Enter Brand Slug

Toggle ON and provide your custom brand name (e.g. mybrand).

4
Save & Enjoy

Save settings. The backend URL is instantly rebranded across all internal sessions.
